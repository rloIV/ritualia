# Ritualia — website

The marketing site and legal pages for **Ritualia**, an Android app for a skincare routine that
changes over time: ramp-up schedules for strong actives, products that alternate nights, and
missed days that stay owed instead of piling up.

Static HTML and CSS. No build step, no JavaScript framework, no trackers.
